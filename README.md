# MapOverlay — Emme4 반투명 지도 오버레이

Emme4 네트워크 편집 창 위에 사전에 캡처한 지도 이미지를 반투명하게 띄워두고,
필요할 때만 오버레이를 "편집 모드"로 전환해 위치/배율/투명도를 조절하는
AutoHotkey v2 스크립트입니다. Emme4 자체는 전혀 건드리지 않으며, 별도의
독립 실행 프로그램으로 동작합니다.

## 요구 사항

- Windows
- [AutoHotkey v2](https://www.autohotkey.com/) 설치 (v1과 호환되지 않으므로 반드시 v2 설치)

## 실행 방법

1. `MapOverlay.ahk`를 더블클릭해서 실행
2. 처음 실행 시 지도 이미지 파일(png/jpg/bmp/gif)을 선택하는 창이 뜸
3. 오버레이가 화면에 반투명하게 나타나며, 시작 시에는 "편집 모드" 상태

## 단축키

| 단축키 | 동작 | 비고 |
|---|---|---|
| `Ctrl+Alt+T` | 편집 모드 ↔ 클릭 통과 모드 전환 | 언제나 동작 |
| `Ctrl+Alt+H` | 오버레이 완전히 숨김 ↔ 표시 전환 | 언제나 동작 |
| `Ctrl+Alt+Q` | 설정 저장 후 종료 | 언제나 동작 |
| 좌클릭 드래그 | 오버레이 위를 클릭한 채로 끌어서 이동 | 편집 모드에서만 |
| 방향키 | 오버레이 1px 미세 이동 | 편집 모드에서만, 클릭 통과 모드에서는 Emme4로 그대로 전달됨 |
| `Shift + 방향키` | 오버레이 10px 이동 | 편집 모드에서만 |
| `Shift + 마우스휠` | **마우스 커서 위치를 기준으로** 확대 / 축소 (5% 단위) | 편집 모드에서만, 클릭 통과 모드에서는 Emme4로 그대로 전달됨 |
| `Ctrl+Alt+Up` / `Ctrl+Alt+Down` | 투명도 증가 / 감소 | 편집 모드에서만 |
| `Ctrl+Alt+O` | 다른 지도 이미지로 교체 | 편집 모드에서만 |
| `Ctrl+Alt+R` | 참조점 기반 반자동 정렬 시작 | 아래 참고, 언제나 시작 가능 |
| `Esc` | 정렬 진행 중 취소 | 정렬 중이 아니면 무시됨(Emme4로 그대로 전달) |

**클릭 통과 모드**가 실제로 Emme4 네트워크 편집을 위한 모드입니다. 이 모드에서는
오버레이가 화면에 그대로 보이지만 모든 마우스 클릭/휠이 오버레이를 투명하게 통과해
아래의 Emme4 창으로 전달됩니다(`WS_EX_TRANSPARENT`).

**편집 모드**는 지도 위치/배율/투명도를 다시 맞출 때만 짧게 전환해서 쓰는 모드입니다.

**`Ctrl+Alt+T`(모드 전환)와 `Ctrl+Alt+H`(숨김/표시)의 차이**: `Ctrl+Alt+T`는 오버레이를
보이는 상태로 유지하되 클릭이 통과되게/안 되게 바꾸는 것이고, `Ctrl+Alt+H`는 편집 모드
여부와 무관하게 오버레이를 화면에서 아예 안 보이게 껐다 켰다 하는 것입니다. Emme4 화면을
완전히 깨끗하게 보고 싶을 때는 `Ctrl+Alt+H`를 쓰세요.

### 이동/확대·축소가 더 쉬워진 점 (개선 사항)

- **드래그 이동**: 오버레이 위 아무 곳이나 마우스로 누른 채 끌면, 마우스를 놓을 때까지
  실시간으로 창이 따라옵니다(이전 버전보다 훨씬 안정적으로 동작하도록 방식을 교체함).
- **방향키 이동**: 마우스 없이도 방향키로 1px, `Shift+방향키`로 10px씩 정밀하게 옮길 수 있습니다.
- **커서 기준 확대/축소**: 이전 버전은 항상 왼쪽 위 모서리를 고정한 채 커지고 작아져서
  원하는 지점을 맞추기 어려웠는데, 이제는 **마우스 커서가 가리키는 지점이 화면에서
  고정된 채로** 확대/축소되어, 정렬하고 싶은 지점 위에서 휠을 굴리면 그 지점 기준으로
  자연스럽게 비율이 조정됩니다.

## 스케일(줌) 동기화 방법

Emme4의 확대/축소 비율을 프로그램적으로 읽어올 방법이 없기 때문에(그게 가능했다면
onmap 문제 자체가 없었을 것), 두 가지 정렬 방법을 제공합니다.

### 방법 1: 수동 정렬

1. Emme4에서 네트워크를 원하는 배율로 확대/축소
2. `Ctrl+Alt+T`로 편집 모드 전환
3. `Shift+휠`로 오버레이 이미지를 Emme4 네트워크와 눈으로 맞춰 확대/축소, 드래그로 위치 정렬
4. `Ctrl+Alt+T`로 다시 클릭 통과 모드로 전환해 편집 재개

### 방법 2: 참조점 기반 반자동 정렬 (`Ctrl+Alt+R`)

지도 이미지와 Emme4 화면에서 같은 지점(교차로, 랜드마크 등) 2곳을 순서대로 클릭하면,
두 기준점 사이의 거리 비율로 배율을, 기준점 1의 위치 차이로 이동량을 자동 계산해
오버레이에 즉시 적용합니다. 기준점 2곳은 서로 멀리 떨어져 있을수록(예: 지도 좌상단과
우하단 부근의 교차로) 배율 계산 오차가 줄어듭니다.

1. `Ctrl+Alt+R` 입력 → 자동으로 편집 모드로 전환되고 정렬 절차 시작
2. **정렬 1/4**: 지도 이미지 위에서 기준점 1(예: A 교차로)을 클릭
3. **정렬 2/4**: 지도 이미지 위에서 기준점 2(예: B 교차로)를 클릭
4. **정렬 3/4**: (자동으로 클릭 통과 모드로 전환됨) Emme4 화면에서 기준점 1과
   동일한 지점(같은 A 교차로)을 클릭 — 이 클릭은 Emme4에도 그대로 전달되므로
   Emme4에서 해당 지점이 선택/클릭되는 것은 정상입니다
5. **정렬 4/4**: Emme4 화면에서 기준점 2와 동일한 지점(같은 B 교차로)을 클릭
   → 배율/위치가 자동 계산되어 오버레이가 즉시 맞춰지고, 클릭 통과 모드로 유지됩니다
6. 언제든 `Esc`로 정렬을 취소할 수 있습니다(진행 중이 아닐 때는 `Esc`가 평소처럼
   Emme4로 전달됩니다)

이 방식은 순수 이동+배율(회전 없음)만 계산하므로, 캡처한 지도 이미지와 Emme4 화면이
회전 없이 같은 방향(북쪽이 위)으로 정렬돼 있다는 전제가 필요합니다.

설정(이미지 경로, 배율, 위치, 투명도)은 종료 시(`Ctrl+Alt+Q`) `MapOverlay.ini`에 저장되어
다음 실행 때 그대로 복원됩니다. (참조점 정렬 진행 상태 자체는 세션 간 저장되지 않습니다.)

## 이 세션에서 확인한 것 / 확인하지 못한 것

AutoHotkey는 Win32 GUI에 의존하는 Windows 전용 런타임이라, 이 코드를 작성한
리눅스 원격 환경에는 AutoHotkey도 wine도 설치되어 있지 않아 **실제 실행 검증은
하지 못했습니다.** 대신 다음 원칙으로 위험을 낮췄습니다:

- 문서화가 불확실한 트릭(예: Picture 컨트롤 `.Value` 재할당으로 이미지 교체)은 배제하고,
  이미 검증 경로로 쓰인 `CreateOverlay()`를 재사용해 창을 다시 만드는 방식으로 대체
- 드래그 이동 / 방향키 이동 / 기준점 클릭 캡처는 모두 `MouseGetPos`, `GetKeyState`,
  `Gui.Move`/`Gui.GetPos` 같은 표준 AHK 함수만으로 구현(이전 버전에서 쓰던
  `WM_LBUTTONDOWN` 메시지 후킹 + `WM_NCLBUTTONDOWN`/`HTCAPTION` 트릭은 제거).
  좌표를 직접 폴링(`while GetKeyState("LButton","P")`)하는 방식이라 컨트롤 종류나
  메시지 전달 여부에 덜 의존적이라 더 신뢰도가 높습니다.
- 클릭 통과 관련 Win32 스타일(`WS_EX_TRANSPARENT`, 0x20)은 AHK/Win32 커뮤니티에서
  오래 검증된 표준 기법만 사용
- 모든 창 대상 함수는 `mapGui` 객체를 직접 넘기지 않고 `"ahk_id " mapGui.Hwnd`로
  명시해 버전 간 인자 처리 차이의 위험을 줄임
- 확대/축소는 커서 위치를 기준(anchor)으로 배율과 창 위치를 함께 재계산하는 단순한
  좌표 기하 계산만 사용(회전 없는 순수 스케일+이동)
- 참조점 정렬은 두 점 사이 유클리드 거리 비율로 배율을 구하는 단순 기하 계산만 사용

따라서 **아래 체크리스트로 실제 Windows/Emme4 환경에서 한 번은 직접 검증**해 주세요.
문제가 있으면 알려주시면 바로 수정하겠습니다.

## 수동 검증 체크리스트 (Windows + Emme4에서)

- [ ] 스크립트 실행 시 이미지 선택 창이 뜨고, 이미지를 고르면 오버레이가 반투명하게 표시된다
- [ ] Emme4를 켜고 오버레이 아래에 Emme4 네트워크 창을 배치한 상태에서, `Ctrl+Alt+T`로
      클릭 통과 모드로 전환 → 오버레이가 보이는 상태에서도 Emme4의 링크/노드를 정상적으로
      클릭·드래그·선택할 수 있다
- [ ] 다시 `Ctrl+Alt+T`로 편집 모드 전환 → 오버레이 위에서 좌클릭한 채로 마우스를 끌면
      창이 실시간으로 따라오고, 마우스를 놓으면 그 자리에 멈춘다
- [ ] 편집 모드에서 오버레이 밖(예: 바탕화면, 다른 창)을 클릭한 채로 끌어도 오버레이가
      움직이지 않는다(오버레이 위에서 시작한 드래그만 반응해야 함)
- [ ] 편집 모드에서 방향키를 누르면 오버레이가 1px씩, `Shift+방향키`는 10px씩 이동한다
- [ ] 클릭 통과 모드에서 방향키를 누르면 오버레이는 움직이지 않고, Emme4 쪽에서
      방향키가 평소처럼 동작한다(예: 뷰 이동, 선택 이동 등 Emme4 자체 기능)
- [ ] 편집 모드에서 지도 위 특정 지점에 마우스를 올리고 `Shift+휠`을 굴리면, 그 지점이
      화면상 같은 위치에 고정된 채 이미지가 비율을 유지하며 커지고 작아진다
      (모서리가 아니라 커서 위치 기준으로 확대/축소되는지 확인)
- [ ] 클릭 통과 모드에서 `Shift+휠`을 굴렸을 때 오버레이는 반응하지 않고, 휠 스크롤이
      Emme4 창으로 정상 전달된다(Emme4에 휠 확대 기능이 있다면 그게 동작해야 함)
- [ ] `Ctrl+Alt+Up`/`Down`으로 투명도가 단계적으로 바뀐다
- [ ] `Ctrl+Alt+H`를 누르면 모드(편집/클릭통과)와 무관하게 오버레이가 화면에서 완전히
      사라지고, 다시 누르면 같은 위치·배율로 다시 나타난다
- [ ] `Ctrl+Alt+O`로 다른 이미지를 선택하면 같은 위치에 새 이미지로 오버레이가 다시 생성된다
- [ ] `Ctrl+Alt+Q`로 종료 후 다시 실행하면, 마지막 이미지·위치·배율·투명도가 그대로
      복원된다 (`MapOverlay.ini` 확인)
- [ ] 편집 모드가 아닌 상태에서 `Ctrl+Alt+O`, `Shift+휠`, `Ctrl+Alt+Up/Down`, 방향키를
      눌러도 오버레이 쪽은 아무 일도 일어나지 않는다(의도된 동작, 단 `Ctrl+Alt+T`/
      `Ctrl+Alt+H`/`Ctrl+Alt+Q`는 예외로 항상 동작해야 함)

### 참조점 기반 반자동 정렬 (`Ctrl+Alt+R`) 검증

- [ ] `Ctrl+Alt+R` 입력 시 편집 모드로 전환되고 "정렬 1/4" 툴팁이 뜬다
- [ ] 지도 이미지 위 한 지점(예: 특정 교차로)을 클릭하면 "정렬 2/4"로 넘어간다
      (이때 창이 드래그되어 움직이지 않아야 함)
- [ ] 지도 이미지 위 다른 지점을 클릭하면 자동으로 클릭 통과 모드로 바뀌며
      "정렬 3/4" 툴팁이 뜬다
- [ ] Emme4 화면에서 같은 첫 번째 지점을 클릭하면 그 클릭이 Emme4에도 정상 전달되고
      (예: 해당 노드가 선택됨), "정렬 4/4"로 넘어간다
- [ ] Emme4 화면에서 같은 두 번째 지점을 클릭하면 오버레이의 배율/위치가 자동으로
      바뀌어 두 기준점이 지도-Emme4 화면 상에서 겹쳐 보인다
- [ ] 정렬 완료 후 클릭 통과 모드가 유지되어 바로 Emme4 편집이 가능하다
- [ ] 정렬 1/4~4/4 진행 중 `Esc`를 누르면 즉시 취소되고, 정렬 중이 아닐 때 `Esc`는
      평소처럼 Emme4로 전달된다(Emme4의 취소 동작이 막히지 않아야 함)
- [ ] 정렬 진행 중 `Ctrl+Alt+O`(이미지 교체)를 누르면 무시되고 안내 메시지만 뜬다

## 알려진 제한 / 다음 단계 아이디어

- 참조점 정렬은 이동+배율만 계산(회전 보정 없음) — 캡처 이미지와 Emme4 화면의
  방위가 같다는 전제 필요
- 여러 장의 지도(레이어)를 순환하며 겹쳐 보는 기능
- Emme4 창이 최소화/전환될 때 오버레이를 자동으로 숨기는 옵션(현재는 `Ctrl+Alt+H`로 수동)
- 방향키 미세 이동은 항상 전역으로 등록되어 있어(편집 모드가 아니면 아무 동작 안 함),
  혹시 Emme4에서 방향키 관련 이상 동작이 관찰되면 알려주시면 단축키를 다른 조합으로 변경하겠습니다
